# SE12 – Programming for the Web  
## Teacher Reference Index

This folder contains the **teacher‑only** version of the Programming for the Web unit.  
It mirrors the student booklet but includes:

- teaching notes  
- exemplar explanations  
- common misconceptions  
- differentiation strategies  
- marking insights  
- troubleshooting notes  

Use this version when planning lessons, supporting students, and marking submissions.

---

## 📘 Core Teacher Files

### **1. Unit Overview**  
`unit-overview.md`  
Provides a teacher‑focused summary of syllabus outcomes, key concepts, and pedagogical priorities. Includes notes on pacing and integration with other SE12 content.

### **2. Task Description**  
`task-description.md`  
The full assignment brief with teacher annotations, clarifications, and intent notes.  
Includes guidance on how to introduce the task and what to emphasise.

### **3. Steps to Success**  
`steps-to-success.md`  
A scaffolded breakdown of the assignment workflow with teacher commentary on:

- where students typically struggle  
- checkpoints to run in class  
- opportunities for formative assessment  

### **4. Glossary**  
`glossary.md`  
All student terms plus teacher notes on how to teach or demonstrate each concept.

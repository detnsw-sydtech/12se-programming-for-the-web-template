# Task Description  
### Programming for the Web – Software Engineering Stage 6 (Year 12)

In this task, you will design, develop, test, and present a **Progressive Web App (PWA)** that catalogues a topic of personal interest or meets the needs of a client. Your PWA will include a front‑end interface, a back‑end server, and a SQLite database.

This task assesses your ability to apply software engineering principles, develop secure and functional code, and document your development process.

---

## 🎯 Task Type

- Software solution  
- Project documentation  
- Presentation  

Weighting: **20%**

---

## 📘 Outcomes Assessed

You will be assessed on your ability to:

- Apply structural elements to develop programming code (**SE‑12‑02**)  
- Analyse how hardware, software, and emerging technologies influence software solutions (**SE‑12‑03**)  
- Justify the selection and use of tools and resources (**SE‑12‑06**)  
- Design, develop, and implement safe and secure programming solutions (**SE‑12‑07**)  
- Test and evaluate language structures to refine code (**SE‑12‑08**)  

---

## 🧪 Project Description

You will create a **Progressive Web App (PWA)** that:

- Catalogues a topic of your choice (e.g., music, movies, recipes, games, art, quotes, sports, clothing, etc.)  
- Stores data in a SQLite database  
- Allows users to query and filter information  
- Includes a front‑end interface built with HTML, CSS, and JavaScript  
- Includes a back‑end server built with Node.js and Express  
- Demonstrates secure coding practices  
- Includes documentation and testing  

You may work with a **critical friend** to provide feedback on your UI, UX, and functionality, but all submitted work must be your own.

---

## 📦 Submission Requirements

You must submit **three components**:

---

### **Component A – Project Documentation**

Your documentation must include:

- Process diary / logbook  
- Storyboard or wireframes  
- Directory structure  
- Gantt chart  
- SQL file with all queries commented out progressively  
- Testing documentation (including accessibility testing)  

Standardised documentation formats from the syllabus must be used.

---

### **Component B – Software Solution**

Your PWA must include:

#### **User Interface**
- Clear layout and design  
- Accessibility and inclusivity considerations  
- Usability features  

#### **Programming**
- HTML  
- CSS  
- JavaScript  
- SQL  
- Node.js + Express  

#### **Database**
- Table creation with appropriate data types  
- SQL queries  
- Evidence of testing  

#### **Testing**
- Validation  
- User accessibility testing  
- Use of tools such as W3C Validator and Google Lighthouse  

---

### **Component C – Presentation**

You will:

- Present your PWA to the class  
- Demonstrate its features  
- Explain your design and development process  
- Respond to questions

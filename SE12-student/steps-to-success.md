# Steps to Success  
### Programming for the Web – Software Engineering Stage 6 (Year 12)

This guide outlines the key steps you will follow to successfully complete your Progressive Web App (PWA) project. Each step builds on the previous one, helping you move from planning to a fully functional web application.

Use this checklist throughout the unit to track your progress.

---

## ✅ Step 1 — Set Up Your Development Environment

You will:

- Install the required VS Code extensions  
- Install **Node.js**  
- Install **SQLite3**  
- Create a text file listing the core folders for your project  
- Create a text file listing the core files for your project  
- Write and run BASH scripts to automatically generate your folders and files  
- Record a short video showing your automated file generation  

This step ensures your environment is ready for development.

---

## ✅ Step 2 — Set Up the Database

You will:

- Plan and design the tables needed for your catalogue  
- Choose meaningful field names and appropriate data types  
- Write SQL queries to create tables and insert data  
- Comment out each SQL query progressively so all queries are recorded  

This step builds the foundation for storing and retrieving your data.

---

## ✅ Step 3 — Construct the Front‑End JSON File

You will:

- Write a JavaScript algorithm that converts SQL query results into JSON  
- Send the JSON data to the front‑end  

This step connects your database to your user interface.

---

## ✅ Step 4 — Code the Look of the Front End

You will:

- Create wireframes or storyboards for your pages  
- Build your HTML structure  
- Style your pages using CSS  

This step focuses on the visual design and layout of your PWA.

---

## ✅ Step 5 — Code Initial Functionality

You will:

- Insert data into your database  
- Query your database to confirm the data is stored correctly  

This step ensures your database is working as expected.

---

## ✅ Step 6 — Plan Query Options

You will:

- Create an algorithm or IPO table  
- Outline the different queries users can make  
- Plan how users will interact with your catalogue  

This step helps you design a user‑friendly experience.

---

## ✅ Step 7 — Code Remaining Functionality

Using an agile, iterative approach, you will:

- Build out your catalogue container  
- Implement your query options  
- Add interactivity and dynamic behaviour  

This step brings your PWA to life.

---

## ✅ Step 8 — Implement PWA Architecture

You will:

- Add icon sets  
- Configure service workers  
- Prepare your `manifest.json`  
- Enable offline behaviour and caching  

This step transforms your web app into a Progressive Web App.

---

## ✅ Step 9 — Test Your PWA

You will:

- Complete a user accessibility testing document  
- Create test scenarios  
- Use tools such as:
  - **W3C Validator**
  - **Google Lighthouse**

This step ensures your PWA is functional, accessible, and user‑friendly.

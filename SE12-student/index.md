# Programming for the Web  
### Software Engineering Stage 6 (Year 12)

Welcome to the **Programming for the Web** unit.  
In this project, you will design, build, test, and present a **Progressive Web App (PWA)** that stores and queries data using modern web technologies.

This booklet contains the learning activities, theory content, and project steps you will complete throughout the unit.

## 🎯 What You Will Learn

Throughout this unit, you will develop skills in:

- How data moves across the web  
- How web applications are structured  
- Front‑end development using **HTML, CSS, JavaScript**  
- Back‑end development using **Node.js** and **Express**  
- Designing and querying a **SQLite** database  
- Converting SQL results into JSON  
- Building and testing a **Progressive Web App (PWA)**  
- Applying accessibility, usability, and security principles  
- Using Git and GitHub for version control  

---

## 🧪 Your Major Project

You will create a **Progressive Web App** that:

- Catalogues a topic of personal interest  
- Stores data in a SQLite database  
- Allows users to query and filter information  
- Includes a front‑end interface and back‑end server  
- Demonstrates good coding practices  
- Includes documentation and testing  

You will submit:

- **Component A:** Project documentation  
- **Component B:** Software solution  
- **Component C:** Presentation  

Full details are in the [Task Description](task-description.md).

---

## 🚀 Getting Started

1. Install **Node.js**  
2. Install **SQLite**  
3. Install the recommended VS Code extensions  
4. Follow the steps in the [Steps to Success](steps-to-success.md) guide  
5. Build your PWA step by step  

Your teacher will guide you through each stage of the project.

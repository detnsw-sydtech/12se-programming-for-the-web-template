# Unit Overview  
### Programming for the Web – Software Engineering Stage 6 (Year 12)

This unit introduces you to the foundations of web development and guides you through building a **Progressive Web App (PWA)**. You will learn how data moves across the web, how front‑end and back‑end systems work together, and how to design and implement a complete software solution.

The unit is delivered through a mix of theory, practical activities, and project‑based learning. You will complete a major project alongside the theory lessons.

---

## 📅 Unit Structure

### **Weeks 1–2**
- Complete a pre‑test on web fundamentals  
- Explore applications of web programming  
- Learn how data is transferred on the internet  
- Set up your development environment  
- Install Node.js, SQLite, and VS Code extensions  
- Create scripts to generate files and folders  
- Begin planning your PWA project topic  

### **Weeks 3–4**
- Investigate web security concepts  
- Explore the role of the W3C  
- Learn how browsers influence web development  
- Study CSS and front‑end design principles  
- Create wireframes or storyboards  
- Build the front‑end structure using HTML and CSS  

### **Weeks 5–6**
- Learn about version control and open‑source software  
- Explore code libraries and performance optimisation  
- Study content management systems (CMS)  
- Investigate back‑end processes  
- Design your database tables  
- Write SQL queries and test your database  
- Begin coding initial functionality  

### **Weeks 7–9**
- Compare SQL and Object‑Relational Mapping (ORM)  
- Learn about collaboration between front‑end and back‑end developers  
- Set up your Express web server  
- Render your front‑end through the server  
- Build out your catalogue and query options  
- Add icons and configure PWA services  

### **Week 10**
- Test your PWA using W3C and accessibility tools  
- Complete user accessibility testing  
- Present your PWA to the class  
- Submit your documentation and code  

---

## 🎯 Learning Outcomes

By the end of this unit, you will be able to:

- Apply structural elements to develop programming code  
- Analyse how hardware, software, and emerging technologies influence web solutions  
- Justify the selection of tools and resources  
- Design and implement safe and secure programming solutions  
- Test and evaluate code to refine functionality  

These outcomes align with the Software Engineering Stage 6 syllabus.

---

## 🧩 Project Focus

Your major project is a **Progressive Web App** that:

- Catalogues a topic of personal interest  
- Stores data in a SQLite database  
- Allows users to query information  
- Includes a front‑end interface and back‑end server  
- Demonstrates good coding practices  
- Includes documentation and testing  

You will work on this project throughout the unit.
